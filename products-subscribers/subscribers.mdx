---
title: "Subscribers"
description: "View, filter, search, and export waitlist subscribers for back-in-stock, price-drop, and coming soon alerts."
---

The **Subscribers** page lists every shopper who joined a Stocksy waitlist. Open it from the Stocksy app sidebar or from **View All Subscribers** on the Home dashboard.

Use this page to review who subscribed, which product they chose, which alert type they used, and whether they were already notified.

## Filter by alert type

Tabs at the top filter the list:

| Tab | Shows |
| --- | --- |
| **All** | Every subscriber across all alert types |
| **Back in Stock** | Subscribers waiting for restock alerts |
| **Price Drop Alert** | Subscribers waiting for price-drop alerts |
| **Coming Soon** | Subscribers on coming-soon waitlists |

## Search subscribers

Use the search bar to find subscribers by:

- Name
- Email
- Phone
- Product

Search works with the active tab, so you can narrow results by alert type first, then search within that tab.

## Subscriber table

Each row shows one subscription:

| Column | Description |
| --- | --- |
| **Checkbox** | Select one or more rows for export |
| **No.** | Row number in the current list |
| **Name** | Subscriber name |
| **Email** | Subscriber email address |
| **Phone** | Subscriber phone number (if collected) |
| **Type** | Alert type badge: **Back in Stock**, **Price Drop Alert**, or **Coming Soon** |
| **Status** | Current state of the subscription (for example, **Notified**) |
| **Channels** | How the shopper asked to be contacted (for example, **Email**) |
| **Date** | When they subscribed |
| **Product** | Product and variant they subscribed to |

## Export subscribers

You can export subscribers in two ways:

1. **Export selected rows** — select checkboxes for the rows you want, then export.
2. **Export all** — click **Export all** in the top-right to export everyone in the current tab and search results.

The helper text on the page reminds you: select rows to export, or use **Export all** for this tab and search.

<Tip>
  To export only one alert type, open that tab first (for example, **Coming Soon**), optionally search, then click **Export all**.
</Tip>
