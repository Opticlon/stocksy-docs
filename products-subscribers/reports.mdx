---

The **Reports** page shows every notification Stocksy has queued or sent. Open it from the Stocksy app sidebar or from **View Reports** on the Home dashboard.

Use this page to track delivery status across back in stock, price drop, and coming soon alerts.

## Filter by status

Tabs at the top filter notifications by status:

| Tab | Shows |
| --- | --- |
| **All** | Every notification record |
| **Pending** | Notifications waiting to send |
| **Processing** | Notifications currently being sent |
| **Sent** | Notifications delivered successfully |
| **Failed** | Notifications that did not send |

## Search reports

Use the search bar to find records by:

- Customer name
- Email
- Phone
- Product
- Variant

Search works with the active status tab.

## Reports table

Each row is one notification attempt:

| Column | Description |
| --- | --- |
| **No.** | Row number in the current list |
| **Customer** | Subscriber name |
| **Email** | Subscriber email |
| **Product** | Product the alert is for |
| **Variant** | Product variant |
| **Type** | Alert type badge: **Back In Stock**, **Price Drop**, or **Coming Soon** |
| **Channel** | Delivery channel (for example, **Email**) |
| **Status** | Current state (for example, **Sent**, **Pending**, **Failed**) |
| **Attempts** | How many times Stocksy tried to send this notification |
| **Created** | When the notification record was created |
| **Sent** | When the notification was successfully sent |
| **Wallet** | Wallet usage for this send, if any |

## Export CSV

Click **Export CSV** in the top-right to download the current report data.

Export uses the active status tab and search filter, so you can export only failed sends or only one product’s notifications if you filter first.

<Tip>
  If a notification shows **Failed**, check **Attempts**, then review [Email notifications](/widgets-emails/email-notifications) delivery settings and your plan quota or wallet balance.
</Tip>
