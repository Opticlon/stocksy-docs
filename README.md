# Stocksy Back in Stock Docs

Documentation site for **Stocksy: Back in Stock**, built with [Mintlify](https://mintlify.com).

## Development

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Structure

| Section | Path |
| --- | --- |
| Get Started | `get-started/` |
| Widgets & Emails | `widgets-emails/` |
| Products & Subscribers | `products-subscribers/` |
| Plans & Billing | `plans-billing/` |
| Troubleshooting & FAQs | `troubleshooting-faqs/` |

Site config lives in `docs.json`. Screenshots live in `images/`.
