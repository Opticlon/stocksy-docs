title: "Coming soon waitlist widget"
description: "Select launch products and customize the Coming soon waitlist button, form, and success message. Available on paid plans only."
---

Use the **Coming soon waitlist** customize screen to choose launch products and control how shoppers join the waitlist. Open it from **Widgets > Coming soon waitlist > Customize**.

<Note>
  Coming soon waitlist is available on **paid plans only**. It is not included on the free plan. Upgrade from **Plan Usage** on the dashboard or [Pricing & plans](/plans-billing/pricing-plans) to unlock this widget.
</Note>

The page header shows:

- A short description of the widget
- **Extension status** — should be **Active** when the theme extension is connected

The editor has four tabs:

1. **Products**
2. **Button placement**
3. **Form content**
4. **Success message**

## Products

Use the **Products** tab to choose which products use the Coming soon waitlist.

### Coming soon products

1. Open the **Products** tab.
2. Click **Add product**.
3. Select the launch products you want on the waitlist.
4. Save your selection.

If no products are selected yet, the page shows **No products selected yet.**

### When the widget shows or hides

| Inventory | Storefront behavior |
| --- | --- |
| **Inventory is 0** | Coming soon waitlist widget is shown on that product page |
| **Inventory is available (in stock)** | Coming soon waitlist widget is hidden on the storefront |

Only products you add in this list can show the Coming soon widget. When stock returns:

- Waitlist shoppers are notified
- The product is removed from the Coming soon products list
- The widget stays hidden on the storefront while the product is in stock

<Tip>
  Set inventory to **0** for a selected launch product when you want shoppers to see the waitlist widget.
</Tip>

## Button placement

Use this tab to control the storefront **Notify me** button for coming-soon waitlist signups. Settings appear on the left. A live preview updates on the right as you edit.

### Settings

| Field | What it controls |
| --- | --- |
| **Message before subscribe** | Button label before the shopper joins the waitlist (for example, `Notify me when available`) |
| **Message after subscribe** | Message shown after the shopper has already joined |

### Style

| Setting | What it controls |
| --- | --- |
| **Font size** | Separate sizes for **Desktop** and **Mobile** |
| **Font transform** | Text casing (for example, Normal) |
| **Border thickness** | Button border width |
| **Border radius** | Corner roundness |
| **Text color** / **Text hover color** | Button text colors |
| **Background color** / **Background hover color** | Button fill colors |
| **Border color** / **Border hover color** | Button border colors |
| **Padding** | Space inside the button |

### Preview

The preview shows a product page mockup with your styled Coming soon button. Use it to confirm text and colors before saving.

## Form content

Use this tab to customize the waitlist popup shoppers see after they click the button.

### Header

| Field | What it controls |
| --- | --- |
| **Title** | Main heading of the form (for example, `Join the waitlist`) |
| **Enable dynamic description** | When on, Stocksy shows the upcoming product and selected variant in the description |
| **Description** | Supporting text under the title |

### Form fields

Configure which fields appear and how they are labeled:

| Field | Options |
| --- | --- |
| **Full name** | Toggle on/off, set **Label** and **Placeholder** |
| **Email address** | Always required. Set **Label** and **Placeholder** |
| **Phone number** | Toggle on/off, set **Label** and **Placeholder** |

Email is required so Stocksy can notify shoppers when the product launches. Optional fields show as optional in the storefront form.

### Preview

The preview shows the modal with:

- Title and description
- Enabled form fields
- **Notify me via** options (for example, Email)
- Submit button (for example, **Notify me**)
- Trust message at the bottom

## Success message

Use this tab to customize what shoppers see after they join the waitlist.

### Content

| Field | What it controls |
| --- | --- |
| **Title** | Success heading (for example, `You're on the list!`) |
| **Description** | Short confirmation text under the title |
| **Confirmation label** | Label shown above the customer's email in the confirmation box |
| **Button text** | Call-to-action button (for example, `Continue shopping`) |
| **Show trust message** | Toggle the privacy/trust line on or off |
| **Trust message** | Trust text shown when the toggle is on |

### Style

| Setting | What it controls |
| --- | --- |
| **Background color** | Success modal background |
| **Corner radius** | Roundness of the success modal container |

### Preview

The preview shows the success modal with the confirmation box (including a sample email), your button text, and the trust message when enabled.

## Save your changes

After you finish editing any tab, save your settings. Then:

1. Confirm your launch products are listed under **Products**.
2. Set inventory to **0** for a selected product.
3. Check the storefront — the Coming soon widget should show.
4. Set inventory back in stock — the widget should hide on the storefront.

<Warning>
  If Coming soon waitlist is locked or unavailable, you are on the free plan. Upgrade to a paid plan to enable this widget.
</Warning>
