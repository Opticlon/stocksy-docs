---
title: "Price drop alert widget"
description: "Customize the Stocksy Price drop alert button, subscription form, and success message with a live storefront preview."
---

Use the **Price drop alert** customize screen to control how shoppers subscribe when they want to know about a lower price. Open it from **Widgets > Price drop alert > Customize**.

The page header shows:

- A short description of the widget
- **Extension status** — should be **Active** when the theme extension is connected

The editor has three tabs:

1. **Button placement**
2. **Form content**
3. **Success message**

Settings appear on the left. A live preview updates on the right as you edit.

## Button placement

Use this tab to control the storefront **Notify me** button for price-drop signups.

### Settings

| Field | What it controls |
| --- | --- |
| **Message before subscribe** | Button label before the shopper subscribes (for example, `Notify me on price drop`) |
| **Message after subscribe** | Message shown after the shopper has already subscribed |

### Style

| Setting | What it controls |
| --- | --- |
| **Font size** | Separate sizes for **Desktop** and **Mobile** |
| **Font transform** | Text casing (for example, Normal) |
| **Border thickness** | Button border width |
| **Border radius** | Corner roundness |
| **Text color** / **Text hover color** | Button text colors |
| **Background color** / **Background hover color** | Button fill colors |
| **Border color** / **Border hover color** | Button border colors |
| **Padding** | Space inside the button |

### Preview

The preview shows a product page mockup with your styled Price drop alert button. Use it to confirm text and colors before saving.

## Form content

Use this tab to customize the subscription popup shoppers see after they click the button.

### Header

| Field | What it controls |
| --- | --- |
| **Title** | Main heading of the form (for example, `Notify me on price drop`) |
| **Enable dynamic description** | When on, Stocksy automatically shows the product and selected variant in the description |
| **Description** | Supporting text under the title |

### Form fields

Configure which fields appear and how they are labeled:

| Field | Options |
| --- | --- |
| **Full name** | Toggle on/off, set **Label** and **Placeholder** |
| **Email address** | Always required. Set **Label** and **Placeholder** |
| **Phone number** | Toggle on/off, set **Label** and **Placeholder** |

Email is required so Stocksy can send the price-drop notification. Optional fields show as optional in the storefront form.

### Preview

The preview shows the modal with:

- Title and description
- Enabled form fields
- **Notify me via** options (for example, Email)
- Submit button (for example, **Notify me**)
- Trust message at the bottom

## Success message

Use this tab to customize what shoppers see after they successfully subscribe.

### Content

| Field | What it controls |
| --- | --- |
| **Title** | Success heading (for example, `You're all set!`) |
| **Description** | Short confirmation text under the title |
| **Confirmation label** | Label shown above the customer's email in the confirmation box |
| **Button text** | Call-to-action button (for example, `Continue shopping`) |
| **Show trust message** | Toggle the privacy/trust line on or off |
| **Trust message** | Trust text shown when the toggle is on |

### Style

| Setting | What it controls |
| --- | --- |
| **Background color** | Success modal background |
| **Corner radius** | Roundness of the success modal container |

### Preview

The preview shows the success modal with the confirmation box (including a sample email), your button text, and the trust message when enabled.

## Save your changes

After you finish editing any tab, save your settings so the storefront updates. Then open a product page with the Price drop alert widget to confirm the button, form, and success message look correct.

<Tip>
  Use a clear button label so shoppers understand they are signing up for a price drop — not a restock alert.
</Tip>
